
# Reserva de horas médicas

Proyecto integrador de la asignatura DevOps.

El proyecto consiste en una página web que simula un servicio de reserva de horas médicas utilizando HTML, CSS, Nginx y Docker.

## Objetivos

- Aplicar prácticas DevOps.
- Utilizar Git y GitHub para el control de versiones.
- Ejecutar el servicio mediante Docker.
- Verificar y monitorear el funcionamiento del servicio.
